---

## 🌐 গিটহাব পেজে লাইভ করার নিয়ম (GitHub Pages Setup):

1. [github.com/new](https://github.com/new)-এ গিয়ে একটি নতুন রিপোজিটরি তৈরি করুন:
   - **Repository name:** `byakaranbaz`
   - **Visibility:** `Public`
   - কোনো README বা license টিক দেবেন না, সরাসরি **Create repository** চাপুন।

2. আপনার কম্পিউটারের টার্মিনালে নিচের দুটি কমান্ড চালান (অথবা গিটহাবের পেজে ফাইলগুলো ড্র্যাগ করে আপলোড করে দিন):
   ```bash
   git remote add origin https://github.com/Easinali/byakaranbaz.git
   git push -u origin main
   ```

3. গিটহাবে রিপোজিটরিটি ওপেন করে:
   - **Settings** ট্যাবে যান ➔ বামপাশের মেনু থেকে **Pages**-এ ক্লিক করুন।
   - **Branch:** `main` এবং ফোল্ডার `/(root)` সিলেক্ট করে **Save** দিন।

4. মাত্র ১ মিনিটের মধ্যে আপনার লাইভ সাইট তৈরি হয়ে যাবে:
   - 🌟 মূল ওয়েবসাইট: `https://easinali.github.io/byakaranbaz/`
   - 🛡️ প্রাইভেসি পলিসি: `https://easinali.github.io/byakaranbaz/privacy.html`
